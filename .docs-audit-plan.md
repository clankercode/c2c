## Verified facts (2a–2e)

### 2a — `c2c instances` deprecated in favour of `c2c dev instances` — CONFIRMED (still works as alias)
- `c2c --help`: `instances [COMMAND] … [DEPRECATED: use c2c dev instances]`.
- `c2c instances` (live run) prints to stderr:
  `[DEPRECATED] c2c instances is now c2c dev instances. Updating in 2 releases.`
  then **still functions** — it listed managed instances (`0 alive / 16 total`).
- `c2c dev instances` is the canonical form: `List managed c2c instances (operator
  view; subcommands: clean-stale, gc)`.
- Verdict: LLM-6 / ON-5 are **ACCURATE** (docs should steer to `c2c dev instances`;
  the alias is not broken, so severity L). NOTE: AF-2 is a **different** issue — it
  is about a nonexistent `dev status` subcommand in a tier-filter note, NOT the
  `instances` alias. Do **not** merge AF-2 into this group.

### 2b — `c2c uninstall` component list — CONFIRMED includes `grok`, no `gemini`
- `c2c uninstall --help` ARGUMENTS: `claude codex kimi opencode grok self git-hook
  git-shim all`. `grok` present; `gemini` absent.
- Verdict: AF-1 **ACCURATE** — CLAUDE.md's list omits `grok`; correct insert is
  `claude|codex|kimi|opencode|grok|self|git-hook|git-shim|all` (no gemini in uninstall).

### 2c — `c2c install gemini` / `c2c start gemini` — CONFIRMED both exist; `grok` too
- `c2c install --help`: clients `claude|codex|codex-headless|opencode|kimi|grok|crush|gemini`.
  `gemini` and `grok` both are install subcommands.
- `c2c start --help` CLIENT enum: `claude, codex, codex-headless, kimi, opencode,
  gemini, crush, tmux, pty, relay-connect`. `gemini` present. (`grok` not a `start`
  client — install-only.)
- `c2c start crush` exits **1** (not 0): prints `[DEPRECATED] crush is no longer a
  first-class c2c client.` → CLAUDE.md's "exit 1" is CORRECT; **audit-cli CLI-5's
  "exit 0" claim is WRONG** (downgrade that detail).
- Verdict: ON-1..4 Gemini-missing findings **ACCURATE**.

### 2d — Claude MCP config default path + binary name — CONFIRMED both drifts real
- `c2c_setup.ml:1422-1423`: default writes `<project_dir>/.mcp.json`; `--global`
  writes `~/.claude.json`. `:2180` comment: "project-scope (the install default
  since #334): <cwd>/.mcp.json". → LLM-3 **ACCURATE**: `docs/llms-claude-install.txt`
  pointing at `~/.claude.json` as default is wrong.
- MCP server is a **separate binary** `~/.local/bin/c2c-mcp-server` (24 MB, exists).
  `c2c mcp-server` → `unknown command mcp-server`. → LLM-4 **ACCURATE**: the doc's
  `c2c mcp-server` must be `c2c-mcp-server`.

### 2e — `c2c watch` and `c2c init <positional room>` — CONFIRMED neither exists
- `c2c watch` → `unknown command watch`. → LLM-1 **ACCURATE**.
- `c2c init --help` SYNOPSIS: `c2c init [OPTION]…` — no positional; room is the
  `-r/--room` flag (`absent=swarm-lounge`). → LLM-2 **ACCURATE** (`c2c init <room-id>`
  positional does not exist).
